# RouteIQ

A comprehensive route optimization and trip planning application built with Laravel (backend) and React + Vite (frontend).

## Project Structure

```
RouteIQ/
│
├── backend/       <-- Laravel API
├── frontend/      <-- React + Vite + Tailwind
└── README.md
```

## Getting Started

### Backend Setup
Navigate to the backend folder and follow Laravel setup instructions.

### Frontend Setup
Navigate to the frontend folder and install dependencies with `npm install`.

## Features

- Trip Planning
- Route Optimization
- Point of Interest (POI) Management
- Cost Analysis
- Multi-stop Route Planning
- Analytics Dashboard
